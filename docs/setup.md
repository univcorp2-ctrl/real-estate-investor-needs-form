# 初期設定ガイド

このリポジトリは、不動産投資家向け買いニーズGoogleフォームを自動生成するためのものです。

## 1. Googleフォームを作成する

1. Google Apps Scriptを開く
2. 新しいプロジェクトを作成
3. `google-apps-script/CreateInvestorNeedsForm.gs` の内容をすべて貼り付け
4. 上部の関数選択で `createInvestorNeedsForm` を選択
5. 実行ボタンを押す
6. 初回のみ、Googleアカウントの権限を許可
7. 実行ログに表示されるURLを開く

実行後、以下が作成されます。

- Googleフォーム編集URL
- Googleフォーム回答URL
- 回答保存用GoogleスプレッドシートURL
- 回答シート内の `ランク判定メモ` シート

## 2. フォーム公開前に確認すること

Googleフォーム編集画面で、以下を確認してください。

- フォームタイトル
- フォーム説明文
- 回答者がログイン必須かどうか
- 回答を1回に制限するかどうか
- 回答通知を受け取るかどうか
- フォームURLを誰に共有するか

## 3. 回答管理

回答は自動作成されたGoogleスプレッドシートに保存されます。

営業・案件紹介では、以下を確認すると優先度を判断しやすくなります。

- 購入希望時期
- 希望購入価格帯
- 自己資金の目安
- 融資の事前相談状況
- 購入意思決定のスピード感
- 最低希望表面利回り
- 許容できるリスク・特殊条件
- 絶対に避けたいNG条件

## 4. ランク判定の運用例

| ランク | 判定目安 | 対応 |
|---|---|---|
| Aランク | 3か月以内に購入希望、予算明確、融資または現金の目処あり、意思決定が早い | 条件一致案件を優先紹介 |
| Bランク | 半年以内に購入希望、条件は明確だが融資確認が必要 | 融資状況確認後に候補紹介 |
| Cランク | 情報収集中、条件が広い、購入時期が未定 | 条件整理の面談を提案 |
| 特別対応 | 高額予算、現金購入、法人購入、継続購入希望、訳あり案件許容 | 水面下案件を個別紹介 |

## 5. 本番運用に必要なもの

- Googleアカウント
- Google Apps Script実行権限
- Googleフォーム作成権限
- Googleスプレッドシート作成権限

この構成では外部API、サーバー、データベース、GitHub Secretsは不要です。

## 6. カスタマイズ方法

質問を変更する場合は、以下の2ファイルを更新してください。

- `google-apps-script/CreateInvestorNeedsForm.gs`
- `src/formSpec.js`

更新後、以下を実行します。

```bash
npm test
npm run lint
```

## 7. 注意点

Googleフォーム本体は、Googleアカウントの権限が必要なため、このリポジトリだけではあなたのGoogle Drive内へ直接作成できません。Apps Scriptを一度実行すれば、フォームと回答用スプレッドシートは自動作成されます。
